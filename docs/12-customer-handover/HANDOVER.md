# Independent-engineer handover

## Required package
Architecture diagrams, source/contract inventory, API schema, data product manifests, environment matrix, service owners, secrets reference IDs (not values), change/rollback playbook, SLO definitions, runbook links, backup/restore evidence, customer training and open risk register.

## Acceptance exercise
A second engineer with no prior project involvement must (1) deploy test fixture, (2) find failing sample screening, (3) trace request and source evidence, (4) identify the correct escalation contact, (5) replay synthetic batch safely and (6) explain the customer export validity controls. Record pass/fail and remediate gaps.

Do not treat verbal handoff or healthy pods as sufficient for G4.
